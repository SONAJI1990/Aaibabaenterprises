# Aai Baba Enterprises Website

Static HTML/CSS/JavaScript website for Netlify Free.

## Files
- index.html
- style.css
- script.js
- images/logo.png

## GitHub
Upload all files to a GitHub repository. Keep `index.html` in the repository root.

## Netlify
Import the GitHub repository into Netlify. For this static site:
- Build command: leave blank
- Publish directory: leave blank or use the repository root

## Netlify Forms
The enquiry form uses `data-netlify="true"`. After deployment, Netlify can detect the form.

## Important
Replace the placeholder gallery blocks with real company/shop/product photos when available.
