# Aai Baba Enterprises — Society Maintenance Website

Responsive static website recreated from the supplied design image.

## Files
- `index.html` — main website
- `style.css` — responsive styling
- `script.js` — service cards, mobile menu and quotation/enquiry modal
- `success.html` — Netlify Forms success page
- `assets/` — logo, hero and service images cropped from the supplied design reference

## GitHub Pages
1. Create a GitHub repository.
2. Upload all files/folders from this project.
3. Go to Settings → Pages.
4. Select `Deploy from a branch`, choose `main` and `/root`.
5. Save and open the GitHub Pages URL.

## Netlify
1. Create a Netlify account.
2. Add new project → Import an existing project.
3. Connect the GitHub repository.
4. Build command: leave empty.
5. Publish directory: `/` (root).
6. Deploy.
7. Netlify Forms is already enabled in the quotation form. After the first deploy, check Netlify → Forms.

## Important
The phone number and email address were intentionally NOT added, as requested.
The green ENQUIRE NOW buttons open the working enquiry/quotation form.
If you later want direct WhatsApp messages, add your WhatsApp number in `script.js` and I can connect every ENQUIRE NOW button to WhatsApp.

For `aaibabaenterprises.com`, add the custom domain in Netlify and then point the GoDaddy DNS records to Netlify as shown by Netlify.
